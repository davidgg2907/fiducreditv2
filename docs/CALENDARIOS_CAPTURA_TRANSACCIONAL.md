# Calendarios: captura compuesta
POST/PUT /api/v1/credit-business-calendars acepta holidays: [{id (solo edición), holiday_date (YYYY-MM-DD), description, recurring}]. GET de detalle devuelve credit_business_holidays sin paginar. Guardado atómico con bloqueo del calendario. No se aceptan IDs ajenos o fechas duplicadas; omitir fechas no las elimina. Las fechas existentes se editan conservando UUID; por política de historial no hay borrado físico. Los endpoints de escritura directa de días inhábiles devuelven 405 para solicitudes válidas; utilizar el calendario. No requiere migraciones. No implementa recálculo retroactivo de vencimientos ni versionamiento de calendarios. Validar compilación y pruebas antes del despliegue.
