# Indicadores operativos
Home de Configuración del Sistema: GET /api/access/operational-dashboard, reservado a manage-access. PLD requiere adicionalmente pld-data.view. Sesión en línea significa sesión vigente según expiración e inactividad, no conexión física del navegador. Historial registra inicios exitosos desde la migración, no refresh ni sesiones antiguas. Las 20 solicitudes se ordenan por creación. Cada sistema muestra hasta 50 eventos, descendentes: eventos de solicitud/workflow/crédito/PLD y escrituras HTTP exitosas atribuidas al encabezado X-Frontend-App (informativo, no prueba de origen). Los registros HTTP no son equivalentes a eventos financieros; no guardan payload, tokens, parámetros de ruta ni evidencia. Las operaciones sin evento de dominio no tienen cliente/folio disponible. No se registran errores ni procesos batch por este middleware. Actualización manual para evitar mantener sesiones activas artificialmente. Los datos de seed existentes pueden aparecer como eventos de dominio. Ejecutar migraciones y CI antes de integrar.
